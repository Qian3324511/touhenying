# touhenying

## 布站记 · 县域气象观测网

在线玩：**https://qian3324511.github.io/touhenying/**

一个单文件网页桌游（`index.html`，无依赖、无联网），已通过 GitHub Pages 发布。

**玩法**（致敬《勃艮第城堡》，要素全部换成气象行业）：
每人一张 37 格的县域网格，6 种地类（地面观测 / 高空探测 / 天气雷达 / 卫星遥感 / 预警服务 / 生态农业）。
每轮两颗骰子，各做一次行动——**取装备**（骰点 n → n 号物资仓）、**布点**（骰点 = 格子点数、同色、相邻已建）、
**上传数据**（卖数据包换分和经费）、**调技术员**（换 2 名，可花 1 名把骰点 ±1）。
铺满一片同色区域按格数得分，25 轮后结算，分高者胜。

- 双人同屏对战 / 单人练习（刷分，记录最高分）
- 手机可直接打开，竖屏自适应
- 本地打开：双击 `index.html` 也能玩

旧版「小气象员 · 接雨滴」（接雨滴小游戏）在 git 历史里，需要时可取回。
