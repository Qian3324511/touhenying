# touhenying · 小气象员 · 接雨滴

一个单文件网页小游戏（`index.html`，无依赖、无联网）。

**玩法**：左右移动水桶接住落下的雨滴得分，躲开冰雹（砸中掉一条命）。三条命，连击有加成。鼠标/手指拖动或方向键控制，空格暂停。

**在线玩**：https://qian3324511.github.io/touhenying/

**本地玩**：双击 `index.html` 用浏览器打开即可。
