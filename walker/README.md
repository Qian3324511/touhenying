# 遛弯勇者 · WALKER HERO

一个零操作的挂机小游戏。按《遛弯勇者_完整设计文档》和《数值体检》表做出来的网页版。

线上地址：https://qian3324511.github.io/touhenying/walker/

## 是什么

你下班了，不想回家。往前走吧。

角色自动前进、自动打怪、自动换装、自动开箱。玩家只需要偶尔看一眼战力、点一下开箱、换一件装备。

- **地图**：5000 米一个区，每 300 米一个小队头目，终点一个 Boss
- **战斗**：战力 = 基础（等级+境界）× 装备乘区 × 元素乘区
- **装备**：9 个部位，7 个品质，词条走加法池，有硬上限
- **境界**：每 60 级突破一次，基础战力 ×1.25，等级不重置，上限 +30
- **Boss**：五种轮流来，各卡一项属性（木攻 / 金攻 / 土抗 / 水抗 / 生命）
- **离线**：关掉网页也在走，回来一次结算（封顶 12 小时）

## 数值怎么来的

对齐《数值体检》表：

| 项 | 文档 | 实现 |
|---|---|---|
| 等级成长 | 1.10 / 1.08 / 1.06 / 1.05 / 1.03 分段 | 同 |
| 境界突破 | ×1.25，等级不重置 | 同 |
| 装备乘区上限 | 2.9 起，每境界 ×1.22 | 同 |
| 元素乘区上限 | 1.80 | 同 |
| Boss 血量 | 小怪 × 20 | 同 |
| Boss 战时长 | 30–47 秒 | 30–45 秒（另加 18 秒保底，防止后期一刀秒）|

两处偏离文档，都是为了网页版能玩：

1. **区域需求增长率**从 1.55 降到 1.28。文档是手游「每天上线一次」的节奏（90 天 26 区），网页版把时间压缩了约 30 倍，1.55 会让玩家在 40 分钟时彻底卡死（战力 / 需求掉到 0.1）。
2. **过关奖励自适应**：每过一区，按当前战力与门槛的比值决定升几级（1–10 级），让战力始终贴着门槛走，而不是越差越远。

60 分钟实测：区 28、等级 150、境界 4、战力 1 亿；比例（战力/需求）从前期 10 倍收敛到 0.6 倍，没有死锁。
